# 여행노트 · GitHub Pages

나 혼자 사용하는 여행 일정·장소·경비 관리 앱입니다. 화면은 GitHub Pages에서, 개인 기록은 별도의 비공개 `sanggeul/travel-note` 저장소 `data/trips.json`에서 관리합니다. Sites 서버나 데이터베이스에 의존하지 않습니다.

## 사용
- GitHub Pages의 앱 주소로 접속합니다.
- 연결 전에는 브라우저 기기 저장 모드로 사용합니다. 기록은 다른 기기에 자동 전달되지 않으며 브라우저 데이터를 지우면 없어질 수 있습니다.
- `GitHub 연결`에서 본인이 발급한 fine-grained personal access token을 입력하면 이후 저장은 비공개 저장소 파일에 반영됩니다.
- 발급 설정: Only select repositories → travel-note / Contents → Read and write. 키는 채팅이나 소스 파일에 넣지 않습니다.
- 키는 sessionStorage에만 두며 여행 JSON·백업에는 포함하지 않습니다. 탭 세션 종료 또는 만료 시 다시 입력해야 할 수 있습니다. 공유 기기에서는 연결 해제하세요.
- 연결 시 기기에서 작성한 새 여행을 원격 기록과 합칩니다. 같은 ID의 수정본은 복사본으로 보존합니다.
- JSON 전체 백업과 가져오기를 지원합니다. 가져오기는 기존 기록을 지우지 않고 새 복사본으로 추가합니다.

## 기능
일별 장소와 순서 / 시간·체류 시간·메모 / 후보·확정·방문 완료 / 원화 기준 항목별 지출 / 예산 잔액 / 이전 여행 복사 / 지도 SDK 클릭 지정 / Google Places 검색.

네이버 장소명 검색은 외부 지도 링크를 이용합니다. 네이버 SDK를 연결하면 지도 클릭 위치를 저장할 수 있습니다. 네이버 검색 Secret이 필요한 서버 경로는 GitHub Pages에 두지 않습니다. Google의 지도 표시·검색은 본인의 제한된 브라우저 API 키 연결 시 동작하며 별도 지도 서비스 요금 정책이 적용됩니다. API 키가 없으면 외부 지도 및 수동 입력을 이용합니다.

## 개발과 배포
Node.js 22+에서 `npm ci`, `npm test`, `npm run build`.
`dist/`를 `docs/`에 복사하여 커밋합니다. GitHub Pages는 main 브랜치의 `/docs` 폴더에서 배포합니다. `docs/.nojekyll`을 유지합니다. GitHub API 쓰기는 SHA를 사용하여 다른 기기 기록을 덮어쓰는 것을 방지합니다.

## 개인정보
이 공개 저장소에는 앱 코드와 명시적인 속초 예시만 있습니다. 실제 개인 여행 데이터나 연결 키를 공개 저장소에 넣지 마세요. 저장 전 원격 저장소가 비공개인지 검사합니다. 앱을 GitHub Pages에서 제공하므로 다른 저장소의 동일 origin 스크립트와 키를 공유하지 않도록 주의하세요.
